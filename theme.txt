# Expense Tracker App — Dark Neon UI Design System

# Overview

This document defines the complete visual design system used for the dark futuristic Expense Tracker mobile application UI.

The goal is to allow another developer, designer, or AI agent to fully recreate the exact same UI style inside Android Studio.

UI Style:

* Dark Theme
* Futuristic
* Neon Glow
* Soft Glassmorphism
* Minimal but premium
* Rounded modern cards
* Gradient-based interactions
* Vibrant accent colors

Platform:

* Android
* Java/XML UI
* Material Design based

---

# Design Philosophy

The UI follows these principles:

1. Deep dark backgrounds
2. Bright neon accent highlights
3. Rounded components
4. Soft glowing buttons
5. Layered card-based layout
6. High contrast readability
7. Minimal clutter
8. Premium cyberpunk-inspired visuals

# Recommended Android Asset Strategy

Use:

* Vector Drawables
* XML Shape Drawables
* WebP only for complex images

Avoid:

* heavy PNG assets
* bitmap-based UI

Recommended:

```text
90% vectors
10% WebP
```

---

# Recommended UI Components

Use:

* rounded cards
* floating buttons
* neon outlines
* soft glassmorphism
* subtle gradients
* minimal borders

Avoid:

* sharp corners
* flat gray UI
* excessive shadows
* overcrowded layouts

# Final Visual Identity Summary

The UI should feel:

* futuristic
* elegant
* premium
* cyberpunk-inspired
* smooth
* modern
* visually immersive

The design language combines:

* dark AMOLED backgrounds
* glowing neon gradients
* rounded modern cards
* smooth layered spacing
* vibrant accents

This design system should be used consistently across:

* splash screen
* dashboard
* analytics
* transaction editor
* settings
* category tree
* dialogs
* bottom navigation
* charts
* widgets

Consistency is extremely important to maintain the premium futuristic appearance.
